## 📖 项目简介

项目聚焦富硒茯茶生产的核心环节，针对传统发花工艺「依赖经验、质量不稳定、效率低下、硒含量难管控」等痛点，研发出集 **AI 视觉识别、5G 物联网、红外光谱技术**于一体的智能发花设备，实现茯茶生产的精准控制与数字化管理。

### 核心技术

- 🤖 **AI 视觉识别系统**：实时监测金花生长状态，分级精度超 98%
- 📡 **红外光谱模块**：实时监测硒含量与发酵状态
- 🌐 **5G 物联网监测大屏**：远程实时监控生产过程
- ♻️ **茶叶梯级利用与处置一体化系统**：智能分级、物尽其用
- 🔧 **「四管」服务模式**：管技术 + 管质量 + 管维修 + 管文创

## 💬 AI小茯 智能助手

页面右下角悬浮入口内置了「AI小茯」问答助手，点击即可打开滑出面板。

- **规则式问答**：无需后端 / API，覆盖团队、成员、智能发花设备、核心技术、发花工艺、项目成效、助农、公益寻人、联系方式等 **17 个话题**，答不上时会友好提示可问方向。
- **语音能力**：支持**语音识别**（说出问题）与**语音朗读**（播报答案），基于浏览器 Web Speech API，推荐 Chrome / Edge。
- **实现位置**：全部逻辑在 `chat.js`（内容数据、意图匹配、语音、UI），样式在 `chat.css`。

## 🚀 本地运行

项目是纯静态站点，无需安装依赖或构建，起一个静态服务器即可：

```bash
cd fuyichangan-promo
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080/`。

> ⚠️ 请通过 HTTP 访问，不要直接用 `file://` 双击打开 `index.html`——否则页内的央视图源（公益寻人图片）和 Font Awesome 图标会因跨域/协议问题加载失败。

## 🌐 部署

零构建，把整个目录上传到任意静态托管平台即可：

- **Vercel**：直接导入仓库（`vercel.json` 已配置 `@vercel/static`）
- **Netlify**：导入仓库，构建命令留空、发布目录设为根目录
- **GitHub Pages**：启用 Pages 指向仓库根目录
